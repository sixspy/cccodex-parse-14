## 落档、幂等与回滚规则

- **幂等钥匙**：每次落档必须携带非空钥匙，空钥匙禁止落档；同一任务内 `(任务, 钥匙)` 唯一。
- **幂等策略（只许一种）**，在「幂等策略」页写定，写进后当天不许换弦，次日方可改写：
  - `SKIP`：幂等撞钥时跳过并计数（累计写入任务的跳过条数）；
  - `FAIL_BATCH`：幂等撞钥时整批失败，并自动撤回到落档前（自动留回滚单）。
  - 点落档时提交的策略若与当前策略不一致，台面直接拦截。
- **争用**：同批两人争抢落档，后到请求记「落档争用失败」，留失败台账与事件，不影响在先批次。
- **回滚单**：回滚必须填缘故；不能由刚才点落档的人自己发起；回滚尚未结束时禁止再次落档。
- **后台执行**：去重落档与回滚都在后台线程执行，台面先受理、可刷新详情看进度；
  回滚详情可读回滚单正文、幂等结果以及落档争用失败字样。
- **落档列表**：每行横排写出跳过条数、已回滚次数、处置策略名。
